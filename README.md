# Let the Truth be Known Ministry Website

A beautiful gospel ministry website themed after **Ancient Israel during the time of Jesus** - featuring Galilean simplicity, Temple grandeur, and parchment manuscript aesthetics.

## ✝️ Theme: Ancient Israel

The entire website has been redesigned with a stunning biblical theme that evokes the Holy Land during Jesus' time:

### Color Palette
- **Temple Blue** (#1e3a5f) - Deep royal blue for primary elements
- **Scarlet** (#8B1538) - Rich temple red for accents
- **Gold** (#B8860B) - Antique gilded accents throughout
- **Parchment** (#F5E6D3, #E8D5B8) - Aged paper backgrounds
- **Olive** (#6B7B3C) - Galilean earth tones
- **Terracotta** (#A0522D) - Desert clay colors

### Typography
- **Cinzel** - Classical Roman/biblical letterforms for headings
- **Lora** - Elegant serif for body text (ancient manuscript feel)
- **Inter** - Clean sans-serif for UI elements

### Design Elements
- Olive branches and grape vine decorations
- Temple column dividers (⛬)
- Gold scroll edges and parchment textures
- Classical borders with temple curtain patterns
- Stone tablet styling for interactive elements
- Candle flicker animations

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/LetTheTruthBeKnown-Website.git

# Navigate to project directory
cd LetTheTruthBeKnown-Website

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
npm run preview
```

## 📚 Features

### Core Features
- **Multi-language Support** - Available in English, Swahili, Amharic, Kinyarwanda, and more
- **Gospel Tracts** - Free downloadable PDF tracts in multiple languages
- **Discipleship Materials** - Structured learning paths with multiple levels
- **Verse of the Day** - Daily scripture with text-to-speech functionality
- **Prayer Request System** - Submit prayer requests to the ministry
- **Salvation Quiz** - Interactive quiz to help people understand salvation
- **Contact Form** - Get in touch with the ministry

### Pages
- **Home** - Ministry overview with features and call-to-action
- **Gospel Tracts** - Browse and download tracts by language
- **Discipleship** - Structured Bible study materials
- **About** - Ministry history and mission
- **Contact** - Contact information and form
- **FAQs** - Frequently asked questions
- **Next Steps** - Guidance for new believers
- **Prayer Request** - Submit prayer requests
- **Salvation Quiz** - Interactive salvation assessment

### Technical Features
- **Responsive Design** - Mobile-first approach
- **Accessibility** - Keyboard navigation, screen reader support
- **Internationalization** - RTL language support
- **Text-to-Speech** - Read scripture aloud
- **PDF Viewer** - In-browser PDF viewing
- **WhatsApp Integration** - Share content via WhatsApp

## 🎨 Design System

### CSS Variables
All design tokens are defined in `src/styles/index.css`:
- Colors, typography, spacing, shadows
- Animation keyframes
- Responsive breakpoints

### Components
All reusable components are in `src/components/`:
- Navbar, Footer, Cards
- Verse of Day, Language Toggle
- PDF Viewer, WhatsApp Share
- Text-to-Speech controls

## 📁 Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/          # Page components
├── context/        # React context (language, theme)
├── hooks/          # Custom React hooks
├── locales/        # Translation files
├── config/         # Configuration files
├── styles/         # Global CSS and variables
├── assets/         # Static assets
└── App.jsx         # Main application
```
